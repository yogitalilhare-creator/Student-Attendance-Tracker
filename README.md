Student Attendance and Performance Tracker

Project Description

This project is developed using Python. It helps to track student attendance and analyze student performance.

Objectives

- To manage student attendance.
- To maintain student records.
- To track student performance.
- To display attendance and performance data using charts.

Technologies Used

- Python
- Pandas
- Matplotlib
- CSV File

Features

- Student attendance tracking
- Data management using CSV files
- Performance analysis
- Data visualization using charts

How to Run

1. Download or clone this repository.
2. Install the required libraries.
3. Run the Python file.
4. View the output.
